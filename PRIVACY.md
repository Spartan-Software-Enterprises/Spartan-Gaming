# Spartan Gaming™ Privacy Policy

**Effective date:** August 17, 2026
**Last updated:** August 17, 2026

Spartan Gaming™ is an open-source, local-first gaming frontend. This policy explains how Spartan Gaming handles data across the European Union General Data Protection Regulation (GDPR), the California Consumer Privacy Act (CCPA), and the Children's Online Privacy Protection Act (COPPA).

---

## 1. Data collection

Spartan Gaming does **not** collect, transmit, store, or sell personal data. There is:

- No server-side data storage operated by Spartan Gaming.
- No telemetry, analytics, or usage tracking sent to Spartan Software Enterprises.
- No advertising, fingerprinting, or cross-site tracking.
- No account creation or registration required to use the application.

All user data remains on the local device where the application is installed.

## 2. Provider sessions and API keys

Spartan Gaming can connect to third-party gaming, streaming, and library services (collectively, "providers"). These integrations work as follows:

- **User-provided credentials only.** Any API key, OAuth token, or login session used to connect to a provider is supplied by the user and stored exclusively in the local application profile on the user's own device.
- **No credential capture.** Spartan Gaming never intercepts, logs, or transmits provider passwords, session tokens, cookies, or API keys to any Spartan Software Enterprises server or any third party.
- **Provider-side authentication.** When a provider requires sign-in, the user authenticates directly with the provider through the provider's own official website or application. Spartan Gaming does not mediate or observe these credentials.
- **User-controlled clearing.** Users can clear all stored provider credentials at any time through Settings > Accounts & API > Clear saved credentials.

## 3. GDPR compliance (European Economic Area / United Kingdom)

Spartan Gaming's local-first architecture means personal data processing under GDPR is minimal:

- **No controller or processor relationship.** Because Spartan Software Enterprises does not collect, access, or store any user data, it does not act as a data controller or data processor under GDPR.
- **No international data transfers.** No user data is transmitted to Spartan Software Enterprises infrastructure. Any data transmitted to third-party providers is governed solely by those providers' own privacy policies.
- **Data portability and erasure.** All data is stored locally. Users can export or delete their data at any time through the application settings. Uninstalling the application removes all local data.
- **Legal basis.** The application operates entirely on-device without processing personal data on behalf of Spartan Software Enterprises, so no additional legal basis for processing is required from Spartan Software Enterprises.

## 4. CCPA compliance (California)

Under the California Consumer Privacy Act and the California Privacy Rights Act:

- **No sale of personal information.** Spartan Software Enterprises does not sell, rent, or share personal information of California residents. There is no data collection to sell.
- **No monetary compensation for data.** Spartan Software Enterprises receives no monetary or other valuable consideration in exchange for personal information.
- **Right to know / right to delete.** Because Spartan Software Enterprises holds no personal data about its users, there is no data to disclose or delete on request. All data resides locally on the user's device under the user's exclusive control.
- **Non-discrimination.** Spartan Gaming is free and open-source. No feature, service, or pricing is contingent on a user's privacy choices.

## 5. COPPA compliance (children under 13)

Spartan Gaming does not knowingly collect personal information from children under 13, and its local-first architecture makes such collection structurally impossible:

- **No data collection.** There is no telemetry, analytics, account system, or server-side component that could collect information from any user, including children.
- **No directed marketing.** Spartan Gaming contains no advertising, no in-app purchases requiring personal data, and no marketing to children.
- **Parental awareness.** Spartan Gaming is an open-source application. Parents and guardians should be aware that third-party provider services accessed through Spartan Gaming may have their own terms, privacy policies, and age requirements. Provider authentication occurs directly with the provider and is outside Spartan Gaming's control.

## 6. Third-party provider services

Spartan Gaming acts as a local interface and does not control, operate, or guarantee the privacy practices of third-party providers (such as cloud gaming services, streaming platforms, or game library clients). When a user authenticates with or uses a provider through Spartan Gaming:

- Authentication occurs directly between the user and the provider.
- Provider terms of service and privacy policies govern that relationship.
- Spartan Gaming does not intercept, store, or relay credentials or session data to or from the provider beyond what the user explicitly initiates through their own device.

Users should review each provider's privacy policy for details on how that provider handles personal data.

## 7. Local data and device storage

All Spartan Gaming data — including settings, profiles, save data, controller mappings, provider session handoffs, and library metadata — is stored locally on the user's device. No data is uploaded to Spartan Software Enterprises servers. Users can:

- Export their data through Settings > Profiles & sync > Export settings.
- Clear credentials through Settings > Accounts & API > Clear saved credentials.
- Clear session data through Settings > Privacy & security.
- Remove all data by uninstalling the application.

## 8. Open-source transparency

Spartan Gaming is open-source software. The complete source code is publicly available for independent review and verification of the privacy guarantees described in this policy. The repository is located at:

<https://github.com/Spartan-Software-Enterprises/Spartan-Gaming>

## 9. Children's privacy summary

Spartan Gaming does not collect personal information from anyone, including children under 13. No parental consent mechanism is required because no data is collected. Third-party providers accessed through the application may have their own age requirements.

## 10. Changes to this policy

If this privacy policy is updated, the changes will be published in the Spartan Gaming repository. Continued use of the application after an update constitutes acceptance of the revised policy. Users are encouraged to review this policy periodically.
