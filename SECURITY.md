# Security Policy

Spartan Gaming handles web content, credentials, controllers, microphones, cameras, screen capture, and potentially remote game input. Security reports are welcome.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository when enabled. If it is unavailable, open a minimal issue asking for a private contact channel without including exploit details.

Do not publicly disclose credentials, access tokens, private stream endpoints, or a working exploit before the project has had a reasonable opportunity to investigate.

## Security principles

- Preserve Chromium sandboxing and site isolation.
- Require explicit, origin-scoped permission for powerful device APIs.
- Treat remote input as high-risk functionality.
- Keep telemetry opt-in and minimize collected data.
- Publish security fixes and affected release versions.
